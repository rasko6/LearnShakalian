This is a Github Pages-powered website created to popularize Shakalian.

What's Shakalian?

  • Shakalian is a language with Slavic-like phonetics, CJK-like glyphs and mostly free word order. It was inspired by many other languages such as Japanese, Tatarian, Russian and Chinese.
